Вариант 1: Хрупкий пол
"5–10% клеток пола при генерации становятся скрытыми ловушками, которые маскируются под обычный пол (.), но хранятся отдельно. При первом шаге на такую клетку выводится предупреждение «Осторожно, скрипучий пол!», а её символ на карте навсегда меняется на запятую (,). При повторном наступании на эту же клетку срабатывает проверка шанса: с вероятностью 50% герой просто проходит дальше с сообщением «Пол скрипит!», а при неудаче пол с треском проламывается — игрок падает на этаж ниже (текущая карта очищается через free(), счетчик глубины увеличивается, генерируется новый этаж, а лестница наверх U не появляется).
